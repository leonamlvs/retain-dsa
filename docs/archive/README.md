# Archive

This directory is for historical documents that are useful for audit/context but are not part of the current specification or normal agent context.

Documents moved here should begin with a clear banner such as:

```text
Historical document — non-normative.
Current behavior is defined by docs/spec/*.
```

Candidates from the previous documentation layout include:

- old `implementation-plan.md`;
- old `implementation-status.md`;
- old `mvp-recovery-plan.md`;
- old `queue-audit-and-completion-plan.md` after the durable incident findings have been extracted;
- superseded standalone Markdown API/database/observability documents once their still-current invariants have been merged into the canonical specs or executable contracts.

Do not load archive files by default during planning or implementation.
